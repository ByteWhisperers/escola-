# Banco de questões

Questões por conceito, criadas pelos agentes a partir do capítulo da OpenStax indicado em cada nota.
Formato sugerido: um arquivo por conceito (`proporcionalidade.md`), cada questão com um id (`prop-001`).
Os gabaritos ficam em `90-Sistema/dados/gabaritos/`, nunca aqui, para não aparecerem antes da resposta.

Vazio por enquanto: o banco cresce a cada sessão.
